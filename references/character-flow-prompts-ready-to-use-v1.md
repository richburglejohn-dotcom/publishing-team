## Notes for Muse

- These are starting points, not guarantees — run the pre-send checklist from `character-flow-prompts-muse-consistency-v1.md` on whatever comes back before sending it over for upload.
- For a scene not covered above (a new combination of characters, a new location), build it from the per-character blocks in that same reference doc using the prompt formula there, rather than inventing wardrobe/build details from scratch.
- If Flow drifts on any of these (wrong apron, wrong build, extra props), regenerate against the same reference image rather than loosening the prompt to match what came out.
